## What to do

1. **`export_format.py`** (new; add it to the CLAUDE.md module layout): the pydantic v1
   models of design §5.2 (`extra="allow"` on read, with a helper that lists unknown keys
   by path for later warnings), `FORMAT = "std-export"`, `FORMAT_VERSION = 1`,
   `SUPPORTED_VERSIONS = (0, 1)` (0 is read by bak-03),
   `build_export() -> ExportDoc` applying the §5.3 ownership table **exactly** (URLs only
   when operator-owned, `image_icon` only for manual / stream / locked Docker, attached
   widgets only, no soft-deleted entries, `secret_set` / `api_key_set` flags, the backup
   schedule without the path, `instance_id` in the header only), deterministic ordering
   (§5.1), and `dump(doc, fmt) -> bytes` (YAML `safe_dump(sort_keys=False,
   allow_unicode=True)` with a short header comment listing what is not included; JSON
   `indent=2`, a trailing newline). Datetimes are UTC ISO 8601 with `Z`.
2. **Scheduled export:** `backups.run_export` writes `YYYY-MM-DD-std_export.yml|json`
   (format from the setting; manual runs timestamped), replacing the entry-list YAML.
   Legacy `-std_backup.yml` keeps being pruned by export retention.
3. **UI download:** `GET /settings/backups/export?format=yaml|json` (admin session),
   `Content-Disposition: attachment; filename="std_export_YYYYMMDD_HHMMSS.yml"`,
   `Cache-Control: no-store`. The Exports card gets **Download YAML** / **JSON**
   (design §12.1). The legacy "Download Full Backup (YAML)" / "Save to server" buttons
   stay until bak-04.
4. **Management API** (all in `mgmt_openapi.OPERATIONS`, request models in
   `mgmt_schemas.py` with `extra="forbid"`, response TypedDicts):
   `GET /settings/backup` (read), `PUT /settings/backup` (write; env-set field → 409;
   reschedules), `GET /backups` (read; no download route), `POST /backups/run` (write;
   `{kind}`; 409 when already running), `GET /export` (read; `?format=json` default or
   `yaml`, YAML as `application/yaml`). Writes are audited through the existing hook
   (`object_type` `backup_settings` / `backup_run`). Reads are not.
5. **`API_REVISION` → 4:** a new `API_REVISION_HISTORY` row `(4, "0.11.0", "backup
   settings, backup list and run, export")`, `FEATURES` gains `"backup"`, and the PRD
   §18.1 table row. bak-04 extends this row's text. It does not bump again.
6. **MCP:** read tools `backup_settings`, `list_backups`, `export_config` (returns the
   JSON document), write tool `run_backup(kind)`. Update `mcp/README.md`'s tool list.
