{% call section_header('Image updates', 'Tell me when a newer image exists for a running container.') %}

Once a day STD asks each image's public registry (Docker Hub, GHCR, Quay, ...) whether a newer tag, or for a moving tag like latest a newer build, exists. It sends the image names, no credentials, and never changes or restarts a container. An available update is information, not a fault: it does not affect health, row colours or the Home Assistant state sensors.

The tag model needs only the notifier's existing data; the digest model (moving tags) needs docker-api-notifier 0.5.0 or later to report the running digest.
