{% call section_header('Image updates', 'Tell me when a newer image exists for a running container.') %}

Once a day STD asks each image's public registry (Docker Hub, GHCR, Quay, ...) whether a newer tag, or for a moving tag like latest a newer build, exists. It sends the image names, anonymously unless you add a Docker Hub login below, and never changes or restarts a container. An available update is information, not a fault: it does not affect health, row colours or the Home Assistant state sensors.

The tag model needs only the notifier's existing data; the digest model (moving tags) needs docker-api-notifier 0.5.0 or later to report the running digest.

Docker Hub login (optional)

Without a login the check spends your public IP's anonymous Docker Hub quota, which every docker pull on your network shares; once it is gone, images show "registry rate limited the check". With a login the check uses your account's quota instead. Create a read-only access token under Docker Hub → Account settings → Personal access tokens (never use your password). The login goes only to auth.docker.io, never to another registry. It is kept in the database, so a database backup contains it.
