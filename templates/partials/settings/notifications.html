Purge MQTT and Home Assistant:

Removes every retained STD message under this channel's base topic and every STD discovery config (Home Assistant devices and entities) from the broker. Other STD installs and the availability topic (<base>/status) are left alone. Use it to start clean; to redo a single entry use the button on its edit page.

Unticked, the broker stays empty until something changes or the channel reconnects.

Scan for orphans:

Looks on the broker for retained STD topics that STD no longer publishes: topics under the base topics this channel used before (STD remembers the last 5), under a base topic you type below, and this install's Home Assistant discovery configs for entries that are gone. Nothing is cleared until you press Clear. Only topics shaped like STD's own are listed.
