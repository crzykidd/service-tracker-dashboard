A stream is a sidecar's inventory (DHCP reservations, a Zigbee bridge, ...) sent to STD with an ingest API key (Settings → API keys). A new stream waits here as pending until you enable it.

An enabled stream is stale after 2 × the interval without a snapshot: Settings is flagged, the health summary lists it and MQTT/Home Assistant report a problem. Its entries keep their own health. Missing entries are only soft-deleted (they come back if the item returns); entries you edited (linked, renamed, locked, grouped, described, icon, URLs, sort priority, widget, Home Assistant, or any check other than an untouched default check) are never removed.
