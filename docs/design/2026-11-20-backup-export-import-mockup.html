Backup & restore

Daily database snapshots, exports of your settings, and import.

ⓘ Learn more

A snapshot is a full copy of the database, secrets and history included. Use it for disaster recovery. An export holds only what you set (groups, URLs you typed, checks, Home Assistant picks, stream filters and blocks, channels, users) and no secrets. Import it on a new install after the notifier and sidecars have posted.

After an import, set these again: ingest keys for sidecars, the notifier api_token, the MQTT password, user passwords, widget API keys and management API keys.

Location

One folder for snapshots and exports.
This folder is outside /config. Make sure it is a mounted volume, or backups are lost when the container is recreated.
